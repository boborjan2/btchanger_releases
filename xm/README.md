# XM for the EU 9-3 NAVI head unit (EHU)

T2App programming packages (Settings > Programming package): the EU NAVI EHU software with XM support for the
btchanger in XM mode (head unit type GM NAV). XM is the CD tab without a disc, shown like an audio CD (title,
artist, channel; play time with btchanger 3.3.1 or later). A disc inserted plays as usual; AM, FM and AUX are stock.

| Package | EHU software | EHU hardware | Tested |
|---|---|---|---|
| navi_xm_12779111_f949f05.zip | 12779111 | 12775955 | bench 2026-11-18 |
| navi_xm_12781855_f949f05.zip | 12781855 | 12780398, 12841613 | built only |

Controls on the XM screen: SEEK = track, << / >> = rewind / fast forward (held), pause, RPT = btchanger pairing,
Random held 3 s = btchanger WiFi setup mode.
